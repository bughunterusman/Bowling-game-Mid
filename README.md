# Bowling Game Mid

A 3D Bowling Game developed in Unity.

## Features
- Realistic ball physics and pin collision detection
- Score tracking and strike detection (`Strike.cs`, `HighScore.cs`, `GameManager.cs`)
- Main Menu and in-game pause/restart menus
- TextMeshPro UI enhancements

## Project Structure
- `Assets/` - Game assets, 3D models, textures, materials, and C# scripts.
- `Packages/` - Unity package manifests and dependencies.
- `ProjectSettings/` - Unity engine project settings and physics configuration.
- `Build/` - Standalone 64-bit Windows build (`Bowling game Mid.exe`).

## Requirements
- Unity 6 / Unity 2022+ LTS
- Windows 10/11 (for the standalone build)
